# 咖啡馆 · 咖啡豆批次与饮品出单

咖啡馆经营管理系统：咖啡豆批次烘焙状态机、饮品菜单、桌台开台/清洁、收银台一条式点单出单（POS）。

## 技术栈

- 后端：Spring Boot 3.3 + Spring Data JPA + MySQL
- 前端：Vue 3 + Element Plus（顶部横向导航、棕色主题）

## 启动

```bash
sh start.sh        # 构建并启动（首次较慢，之后秒级）
sh stop.sh         # 停止
```

启动后访问前端地址（默认 http://127.0.0.1:8312 ）。

## 业务模块

1. **咖啡豆批次**：批次号唯一，烘焙状态机 待烘焙→烘焙中→已入库→已用完，只能逐级前进。
2. **饮品菜单**：名称唯一，价格>0，类别（意式/手冲/非咖啡），状态（在售/下架）。
3. **桌台**：桌号唯一，座位数>0，状态（空闲/占用/清洁中），仅空闲可开台。
4. **收银出单**：左选饮品→中点单流水→右结算；同一桌台仅允许一张未结账账单；账单状态机 制作中→已完成→已结账，结账后释放桌台。
